# Alexandria Williams

Personal website of Alexandria Williams, a journalist and researcher in Köln covering tech policy and how technology moves between China, Africa and Europe.

Live at https://alexandrias-archive.github.io

## What's here

- `index.html`: the main page, with the map, the archive of writing, video and projects, and contact details
- `thesis-presentation.pdf`: my LLM thesis presentation on smart legal contracts in China (2018, restyled in 2026), linked from Projects
- `thesis-slides.pptx`: the same presentation as a PowerPoint file

## Editing the site

Open a file on GitHub, click the pencil icon, make your change and click **Commit changes**. The live site updates within a minute or two.

- To add a piece of work, copy one `<li class="entry">` block in the right list (Writing, Video or Projects) and change the text and link. Each list runs newest first.
- Search the files for `TODO` to find details that still need filling in.
